# VELOOP Data Governance & Analytical Specifications Framework

## 📌 Project Overview
This repository contains the data governance framework, source verification register, and analytical specification pipeline for the **VELoop Rewards Ecosystem**. The project establishes data quality standards, cross-dataset alignment, user lifecycle analytics, reward payout conversions, and wallet risk detection.

---

## 🛠️ Project Architecture & Deliverables

### 1. Data Governance & Verification Register
* **Source & Verification Register (`VELOOP_Task01_Source_Verification_Register`)**: Comprehensive metadata audit, field mapping, and schema validation.
* **Product Area Mapping & Coverage Matrix**: Domain linkage across `Users_1000_Clean` and `VELoop_Rewards_Data_01`.

### 2. Analytical Specifications
* **User Analytics Spec (`User_Analytics_Spec`)**: Tracks Acquisition, Activation rates, DAU/MAU ratios, and churn indicators.
* **Reward Analytics Spec (`Reward_Analytics_Spec`)**: Analyzes task payout liabilities, wallet credits, and referral reward bonuses.
* **Wallet & Withdrawal Analytics Spec (`Wallet_Withdrawal_Spec`)**: Monitors transaction velocity, debit/credit flows, and risk velocity thresholds (>5 transactions/hour).
